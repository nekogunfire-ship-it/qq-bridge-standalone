# v0.2.10 更新与验证

本次更新包含 384 条人物轮廓路径的 30 FPS 流动动画、透明功能面板、完整宽度总览和页面淡入淡出。

## 修复与优化

- 扩展配置、卸载预检、配置导入导出通过明确的 Electron Node 模式启动，避免误启动图形进程。
- 快捷方式使用 WScript 隐藏 Node 控制台；背景进程不再调用 `cmd /c start`。
- 隐藏窗口移除动画背景并暂停 CSS 动画、自动体检与监测刷新；后台服务看门狗保持独立工作。
- 监测请求防重入，非总览/监测页面停止监测刷新，扩展安装状态轮询改为三秒。
- 状态条中的角色/模型名及错误消息按文本显示，避免 HTML 注入。
- 修复连续操作时旧提示定时器提前隐藏新提示的问题。
- 安装步骤失败时返回非零退出码，避免自动化把不完整安装误判为成功。
- 常规视觉测试使用示例配置；在线会话验证需显式 `--live`，防止开发目录和已安装实例混用令牌。
- 发布包排除旧版扫光素材及离线动画生成脚本。

## 验证范围

执行核心质量门禁、依赖审计、安装/覆盖安装数据保留、卸载回归、后台 Node 工作器及 UI 检查。测试详细结果记录在本次 Release 说明中。自动测试不等于完整真人 QQ 端到端验收；系统 GPU 驱动、企业策略和第三方服务配置仍需按实际机器验证。

## 后续更新优先级

1. 性能：可切换静态/30 FPS 背景、透明度滑块，增加帧耗时与内存基准；在确认兼容后提供硬件加速选项。
2. 安装：迁移到更可靠的专用安装器，减少 WScript 依赖，增加签名与升级回滚流程。
3. 首次配置：QQ 接入、API 视觉能力、图片生成采用逐步自动验收，并清楚区分必需项和可选项。
4. 可观测性：提供脱敏诊断包、按请求关联日志和超时阶段提示。
5. 发布：隔离配置的真实 Electron 多尺寸回归、安装/卸载虚拟机测试，以及签名和哈希校验门禁。
