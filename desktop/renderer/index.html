配置与数据

导出会生成一个 config-bundle-*.json 放在仓库根目录。导入时先显示预览， 确认后才覆盖 config.json（覆盖前自动备份到 archive/）。

应用

注意区分：这里是桌面应用本身的重启/退出；「总览」里的重启是重启 QQ 服务，两者互不影响。 退出应用不会停止桥接/DSH 服务。

⚠ 危险区

会先显示影响预览，并询问你的数据（对话历史 / 黑话库 / config.json）是保留、归档还是删除。 确认后由根目录的独立卸载程序接管（本应用会退出，因为不能删除自己正在运行的文件）。

关于

「总览」看服务是否正常；「监测」看 QQ 里正在发生什么；聊天 / 出图 / 角色 / 黑话 / 记忆等 完整功能在网页控制台里（「监测」页可一键打开）。
